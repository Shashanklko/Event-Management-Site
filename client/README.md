# Elysian Client (Prototype - v1)

This folder contains the prototype version of the Elysian Event Management app.

For full features, admin controls, and the updated premium codebase, please visit the [client_v2](../client_v2) directory.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the dev server:
   ```bash
   npm run dev
   ```

Refer to the main [project README](../README.md) in the repository root for detailed documentation.
