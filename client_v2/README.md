# Elysian Client (Production - v2)

This folder contains the refined, fully-featured, and modern version of the Elysian Event Management app.

## Features Included
- **Chapters Narrative Layout:** Welcome (Cinematic video), About, Categorized Events, Lightbox Showcase Gallery, Team, and Contact Us forms.
- **Gmail Web Redirection:** Automatic composing tab launcher pre-filled with visitor query data.
- **Dynamic Contact Data:** Real-time email, office address, and social links manageable via the secure admin portal.
- **Secure Terminal Dashboard:** Admin dashboard to curate events, staff, gallery items, read inquiries, and write email replies directly.
- **Aesthetic Themes:** Premium responsive light & dark mode designs.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the dev server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```

For detailed project details and credentials, refer to the main [project README](../README.md) in the repository root.
